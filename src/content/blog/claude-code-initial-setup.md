## 설정은 조금만, 불편할 때 하나씩

클로드 코드 설정을 검색해 보면 길고 복잡한 설정 파일이 많이 나옵니다. 처음부터 그대로
따라 할 필요는 없습니다. 무엇이 효과가 있었는지 알 수 없게 되고, 서로 부딪히는 지시가
섞이면 오히려 클로드가 말을 덜 듣습니다.

공식 문서에서도 비슷한 기준을 제시합니다. 클로드가 같은 실수를 두 번째 할 때, 지난번에
했던 말을 또 하고 있을 때 설정에 적어 두라는 것이죠.

이 글에서는 막 시작한 단계에서 해 두면 좋은 것만 골랐습니다. 아직 설치 전이라면
[VS Code에서 클로드 코드 쓰기](/claude/claude-code-vscode/)부터 보고 오세요.

## 1. 항상 한국어로 답하게 하기

클로드 코드는 대화를 시작할 때마다 `CLAUDE.md`라는 파일을 먼저 읽습니다. 클로드에게 주는
메모장이라고 생각하면 됩니다. 매번 해야 했던 말을 여기에 적어 두면 따로 말하지 않아도
지켜 줍니다.

이 메모는 두 군데에 둘 수 있습니다.

| 위치 | 적용되는 곳 |
|---|---|
| 내 사용자 폴더의 `.claude/CLAUDE.md` | 내 컴퓨터에서 여는 모든 폴더 |
| 작업 폴더 안의 `CLAUDE.md` | 그 폴더에서만 |

모든 작업에 해당하는 내용은 사용자 폴더 쪽에 적습니다. Windows에서는
`C:\Users\사용자계정이름\.claude\CLAUDE.md`이고, Mac에서는 `~/.claude/CLAUDE.md`입니다.
사용자계정이름은 컴퓨터에 로그인할 때 쓰는 계정 이름입니다. 잘 모르겠다면 파일 탐색기
주소창에 `%USERPROFILE%\.claude`를 입력하고 `Enter`를 누르세요. 그 폴더가 바로 열립니다.

처음 적어 둘 만한 내용은 이 정도입니다.

```markdown
- 모든 답은 한국어로 한다.
- 나는 한국 시간대(KST)를 쓴다. 날짜와 시간은 한국 시간으로 말한다.
- 어려운 용어가 나오면 한 줄로 쉽게 풀어서 설명한다.
- 파일을 고치기 전에 무엇을 바꿀지 먼저 짧게 말한다.
- 코드를 작성할 때는 기능마다 무엇을 하는지 한국어 주석을 붙인다.
- 부탁하지 않은 기능을 덧붙이거나, 관련 없는 코드를 고치지 않는다.
- 기능을 만들거나 고친 뒤에는 직접 실행해서 확인하고, 무엇으로 확인했는지 알려 준다.
```

시간대 줄은 사소해 보여도 넣어 두는 게 좋습니다. 없으면 "오늘", "어제"를 다른 나라 시간
기준으로 계산해서 날짜가 하루씩 어긋나는 일이 생깁니다. 셋째 줄은 막 시작한 단계에서 특히
도움이 됩니다. 모르는 말이 나올 때마다 따로 묻지 않아도 됩니다.

뒤쪽 세 줄은 코드를 만들 때를 위한 것입니다. 주석이 달려 있으면 나중에 코드를 다시 볼 때
무엇을 하는 부분인지 클로드에게 또 묻지 않아도 됩니다. 그다음 줄은 버튼 색 하나 바꿔 달라고
했는데 다른 곳까지 손대는 일을 줄여 줍니다. 바뀐 곳이 적어야 무엇이 달라졌는지 확인하기도
쉽습니다.

마지막 줄은 만들어 놓고 확인하지 않는 일을 막아 줍니다. 화면에 보이는 부분만 만들어 두고
"완료했습니다"라고 하는 경우가 실제로 있습니다. 이 줄이 있으면 만든 뒤에 직접 돌려 보고
결과까지 알려 줍니다.

폴더를 못 찾겠거나 파일 만드는 게 어렵다면 클로드 코드에 부탁하면 됩니다. 입력창에 이렇게
적어 보세요.

```text
내 사용자 폴더의 .claude 폴더에 CLAUDE.md 파일을 만들고 아래 내용을 적어 줘.
(위의 메모 내용을 그대로 붙여넣기)
```

파일을 만들어도 되냐고 물어보면 허락해 주세요. 이미 파일이 있다면 "만들고" 대신 "끝에
추가해 줘"라고 하면 됩니다. 적어 둔 내용은 새로 시작한 대화부터 적용됩니다.

저도 `CLAUDE.md`를 쓰기 전에는 "한국말로 말해 줘", "이 단어 뜻이 뭐야?", "코드에 주석도
달아 줘"처럼 늘 필요한 말을 대화할 때마다 매번 해야 했습니다. 메모에 한 번 적어 둔 뒤로는
이런 말을 따로 꺼낼 일이 없어졌습니다.

메모는 짧을수록 잘 지켜집니다. 공식 문서는 파일 하나에 200줄을 넘기지 말라고 합니다.
서로 반대되는 내용이 있으면 클로드가 아무거나 하나를 따를 수 있으니, 가끔 다시 읽어 보고
안 맞는 줄은 지우세요.

## 2. 폴더마다 메모 남기기

작업 폴더에서 클로드 코드를 열고 `/init`을 입력하면, 클로드가 폴더 안의 파일을 훑어보고
그 폴더용 `CLAUDE.md`를 만들어 줍니다. 이미 파일이 있으면 덮어쓰지 않고 고칠 점을
제안합니다.

만들어진 메모에는 파일을 보면 알 수 있는 내용이 주로 들어갑니다. 여기에 파일만 봐서는
모르는 것을 직접 더해 주세요.

- 건드리면 안 되는 것: "`images` 폴더의 사진은 지우거나 이름을 바꾸지 않는다"
- 이 폴더에서 정한 규칙: "글자 색은 검정과 회색 두 가지만 쓴다"
- 전에 문제가 됐던 일: "버튼 크기를 바꿨다가 모바일에서 글자가 잘렸다. 버튼 크기를 바꾸면
  폭이 좁은 화면에서도 확인한다"

마지막처럼 이유를 한 줄 붙여 두면 좋습니다. 이유를 알면 똑같지는 않은 비슷한 상황에서도
알아서 조심합니다.

## 3. 처음 시작할 권한 모드 정하기

권한 모드는 클로드가 나에게 묻지 않고 어디까지 해도 되는지 정하는 설정입니다.
[1편](/claude/claude-code-what-is/)에서 본 것처럼 Pro, Max, Team 요금제는 Auto 모드로 시작해서,
클로드가 대부분의 일을 묻지 않고 진행합니다.

처음에는 Manual 모드로 시작하는 게 좋습니다. Manual에서는 클로드가 파일을 고치기 전에
무엇을 바꿀지 보여주고 매번 허락을 받습니다. 조금 번거롭지만, 클로드가 어떻게 일하는지
옆에서 지켜보면서 배울 수 있습니다.

대화를 열 때마다 모드를 바꾸기 귀찮다면 클로드 코드에 이렇게 부탁하세요.

```text
앞으로 새 대화는 Manual 모드로 시작하도록 내 사용자 설정을 바꿔 줘.
```

설정을 고쳐도 되냐고 물어보면 허락해 주세요. 쓰다가 매번 허락하는 게 번거로워지면 같은
방법으로 "Auto 모드로 시작하게 바꿔 줘"라고 하면 됩니다.

## 4. 건드리면 안 되는 파일 막기

작업 폴더에 비밀번호 같은 중요한 정보가 담긴 파일이 있다면, 클로드가 아예 열어 보지 못하게
막아 둘 수 있습니다. 개발할 때는 이런 정보를 흔히 `.env`라는 이름의 파일에 모아 둡니다.

`CLAUDE.md`에 "이 파일은 읽지 마"라고 적어 둘 수도 있지만, 메모는 클로드가 지키려고 노력하는
부탁일 뿐입니다. 확실하게 막으려면 설정에 금지 규칙을 넣어야 합니다. 금지 규칙은 어떤
모드에서도 지켜집니다.

이것도 클로드 코드에 부탁하면 됩니다.

```text
내 사용자 설정에 .env 파일은 읽지 못하게 막는 규칙을 추가해 줘.
```

지금 그런 파일이 없다면 이 단계는 건너뛰어도 괜찮습니다.

## 5. 되돌릴 수 있게 저장해 두기

[VS Code 편](/claude/claude-code-vscode/)에서 말했듯이 클로드 코드의 되돌리기 기능은 모든
변경을 되돌리지 못합니다. 그래서 중요한 작업을 하는 폴더라면 git으로 저장 지점을 남겨 두는
게 안전합니다.

git은 폴더 안 파일들의 상태를 시점별로 저장해 두는 프로그램입니다. 게임의 세이브 파일처럼,
저장해 둔 시점으로 언제든 돌아갈 수 있습니다. Windows에서 Git for Windows를 설치했다면 이미
준비는 되어 있습니다.

명령어를 몰라도 괜찮습니다. 클로드 코드에 이렇게 부탁하면 됩니다.

```text
이 폴더를 git으로 관리하게 설정하고, 지금 상태를 저장해 줘.
```

그 뒤로는 큰 부탁을 하기 전에 "지금 상태 저장해 줘"라고 한마디 해 두세요. 결과가 마음에
안 들면 "아까 저장한 상태로 되돌려 줘"라고 하면 됩니다.

## 나중에 해도 되는 것

검색하면 자주 보이지만 지금 당장은 몰라도 되는 것들입니다.

- 플러그인과 스킬: 자주 하는 작업을 명령 하나로 묶어 둔 것입니다. 같은 부탁을 여러 번
  반복하게 됐을 때 찾아보면 됩니다.
- MCP: 클로드 코드를 다른 서비스와 연결하는 방법입니다. 연결할 서비스가 생겼을 때
  알아보세요.
- 훅(hooks): 파일을 고칠 때마다 정해진 명령을 자동으로 실행하게 하는 기능입니다.

## 한눈에 보기

| 할 일 | 방법 |
|---|---|
| 한국어로 답하게 하기 | 사용자 폴더 `CLAUDE.md`에 적기 (어려우면 클로드 코드에 부탁) |
| 폴더별 메모 | 작업 폴더에서 `/init` 후 주의할 점 추가 |
| 시작 모드 정하기 | "Manual 모드로 시작하게 바꿔 줘" |
| 비밀 파일 막기 | ".env 파일 읽기 금지 규칙 추가해 줘" |
| 저장 지점 남기기 | "git으로 관리하게 설정해 줘" |

전부 한 번에 할 필요는 없습니다. 1번만 해 둬도 쓰는 느낌이 꽤 달라집니다. 나머지는 쓰다가
"이건 매번 말하기 귀찮다" 싶을 때 하나씩 더하면 됩니다.
