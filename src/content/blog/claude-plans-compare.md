## 먼저 결론부터

요금제는 "얼마나 자주, 얼마나 길게 쓰느냐"로 고르면 됩니다. 기능 차이보다 사용량 차이가 훨씬
크게 느껴지기 때문입니다.

| 이런 분이라면 | 요금제 |
|---|---|
| 가끔 질문하고 번역이나 요약을 맡기는 정도 | 무료 |
| 거의 매일 쓰고, 무료에서 한도에 자주 걸린다 | Pro |
| 클로드 코드를 써 보고 싶다 | Pro |
| Pro에서도 하루에 몇 번씩 한도에 걸린다 | Max |
| 클로드 코드로 하루 종일 일을 맡긴다 | Ultra |
| 회사에서 2명 이상이 같이 쓴다 | Team |

처음 결제한다면 **Pro를 월간으로 한 달 써 보는 것**을 권합니다. 대부분은 거기서 충분하고 모자라면
그때 올려도 늦지 않습니다.

저도 개인적으로는 Pro를 쓰고 있습니다. 클로드 코드는 Pro부터 쓸 수 있어서 Pro를 골랐습니다.
Pro에서는 Fable을 추가 크레딧 없이 쓸 수 없지만 일반 사용자가 쓰기에는 Opus 5.5로도 충분합니다.

아래 가격과 기능은 2026년 11월 공식 가격 페이지 기준입니다. 요금제는 자주 바뀌니 결제 전에
[공식 가격 페이지](https://claude.com/pricing)에서 한 번 더 확인하세요.

## 한눈에 보기

| | 무료 | Pro | Max | Ultra |
|---|---|---|---|---|
| 가격(월) | 0원 | 20달러 (연간 결제 시 월 17달러) | 100달러 | 200달러 |
| 결제 방식 | — | 월간·연간 | 월간만 | 월간만 |
| 사용량 | 기본 | 무료보다 많음 | Pro의 5배 | 주간 기준 Pro의 10배 |
| 5시간 한도 | 있음 | 있음 | 있음 | 없음 (인증된 계정) |
| 주간 한도 | 있음 | 있음 | 있음 | 있음 |
| 클로드 코드 | 안 됨 | 됨 | 됨 | 됨 |
| Opus 모델 | 안 됨 | 됨 | 됨 | 됨 |
| 프로젝트 | 5개까지 | 제한 없음 | 제한 없음 | 제한 없음 |

가격은 모두 세금이 빠진 금액입니다. 실제로 결제할 때는 세금이 붙고 지역에 따라 원화로 표시될
수 있으니 결제 화면에 나오는 최종 금액을 기준으로 보세요.

## 무료로 어디까지 되나

생각보다 많이 됩니다. 웹, 데스크톱 앱, 휴대폰 앱에서 대화할 수 있고 웹 검색, 파일 올리기,
메모리, 아티팩트 같은 기본 기능도 무료에서 다 씁니다. 모델은 Sonnet과 Haiku를 쓸 수 있습니다.

무료의 한계는 기능보다 **사용량**입니다. 5시간마다 다시 채워지는 한도와 주간 한도가 있는데, 긴 문서를
올리거나 대화를 길게 이어 가면 금방 찹니다. 가끔 쓰는 정도라면 불편함을 거의 못 느끼고 매일
쓰기 시작하면 한도에 자주 걸리게 됩니다.

무료에서는 크게 두 가지가 안 됩니다.

- 클로드 코드를 쓸 수 없습니다
- Opus 모델을 고를 수 없습니다

프로젝트는 5개까지만 만들 수 있습니다. 자료를 올려 두고 반복해서 쓰는 프로젝트를 여러 개 굴릴
생각이라면 이 부분도 걸립니다.

제 경험으로는 일반 채팅만 한다면 무료로도 충분합니다. 다만 클로드 코드를 쓰려면 구독하는 편이
훨씬 낫습니다.

## Pro — 대부분은 여기서 충분합니다

월 20달러입니다. 1년치를 한 번에 결제하면 200달러라서 월 17달러꼴로 조금 쌉니다.

무료와 비교하면 이런 점이 달라집니다.

- 한 번에 쓸 수 있는 사용량이 늘어납니다
- Opus 모델을 쓸 수 있습니다
- 클로드 코드를 쓸 수 있습니다
- 리서치(Research) 기능을 쓸 수 있습니다
- 프로젝트를 개수 제한 없이 만들 수 있습니다

Pro에도 5시간 한도와 별개로 **일주일 한도**가 있습니다. 일주일 동안 쓸 수 있는 총량이 정해져
있다는 뜻입니다. 평소처럼 쓰면 걸릴 일이 드물지만 며칠 몰아서 아주 많이 쓰면 주간 한도에
먼저 닿을 수 있습니다.

연간 결제는 처음부터 고르지 않는 편이 낫습니다. 결제한 금액은 원칙적으로 환불되지 않습니다.
한두 달 월간으로 써 보고 계속 쓸 게 확실해지면 그때 연간으로 바꿔도 됩니다. 월간에서 연간으로
바꾸면 바로 적용되고 쓰지 않은 월간 기간만큼은 첫 연간 요금에서 빼 줍니다.

## Max와 Ultra

Pro와 기능은 거의 같고 **사용량이 훨씬 많은** 요금제가 둘 있습니다. 예전에는 둘 다 Max였고
"Max 5x", "Max 20x"로 나뉘었는데, 지금은 **Max 5x가 Max**, **Max 20x가 Ultra**라는 이름으로
바뀌었습니다. 기존 Max 20x 가입자는 가격 변동 없이 Ultra로 자동으로 옮겨졌습니다.

| | Max | Ultra |
|---|---|---|
| 가격(월) | 100달러 | 200달러 |
| 사용량 | 5시간·주간 모두 Pro의 5배 | 주간 기준 Pro의 10배 |
| 5시간 한도 | 있음 | 없음 (인증된 계정) |
| 매달 받는 API 크레딧 | 100달러어치 | 200달러어치 |

숫자만 보면 Ultra가 예전 20배에서 10배로 줄어든 것처럼 보이지만 기준이 다릅니다. Ultra는
**5시간 한도 없이 주간 한도만** 있는 요금제가 됐습니다. 몇 시간 몰아서 써도 5시간 단위로 끊기지
않고 일주일 총량 안에서만 쓰면 됩니다.

다만 5시간 한도가 없는 건 **인증된 계정**에만 해당합니다. 인증은 계정과 결제 이력 같은 것을 보고
자동으로 이뤄지고 전화번호 인증으로 풀리지는 않습니다. 설정 → 사용량(Usage)에서 "Current
session" 막대가 보이지 않으면 인증된 상태입니다.

Pro에 없는 것도 몇 가지 더 있습니다. 사람이 몰리는 시간에 우선 접근할 수 있고 새 기능을 먼저 써
볼 수 있으며 매달 API 크레딧이 나옵니다. Fable 모델은 Pro에서는 추가 사용 크레딧으로
쓰지만 Max와 Ultra에는 주간 한도의 절반까지 포함돼 있습니다.

Max와 Ultra는 연간 결제가 없고 월간으로만 됩니다. 1년씩 묶이지 않는다는 점에서는 부담이 덜합니다.
다만 Max나 Ultra에서 Pro로 내리는 방법과 적용 시점은 공식 도움말에 따로 나와 있지 않습니다.
나중에 내릴 생각이라면 설정 → 결제 화면에서 어떻게 처리되는지 먼저 확인해 두세요.

둘 중에서는 **Max부터** 시작하세요. Ultra는 클로드 코드로 하루 종일 일을 맡기는 사람에게 맞는
크기입니다. 채팅 위주라면 Max로 써 보고 모자랄 때 올려도 됩니다.

회사에서는 처음에 Pro를 구독해 줬습니다. 그런데 작업량이 많다 보니 한도를 넘기는 일이 잦았고
팀 전체가 쓸 일도 많아서 지금은 회사 계정을 Ultra로 구독해 쓰고 있습니다.

### 쓰는 도중에 올리면

Pro를 쓰다가 Max나 Ultra로 올리면 남은 기간만큼 날짜로 나눠 계산합니다. 이미 낸 Pro 요금은 버리지
않고 남은 기간 몫을 뺀 차액만 냅니다. 연간 Pro를 쓰다가 올렸는데 남은 금액이 새
요금제 요금보다 많으면, 남는 금액은 계정에 적립됩니다. Max에서 Ultra로 올릴 때도 남은 결제 기간만큼
나눠 계산합니다.

## Team과 Enterprise

회사나 팀에서 쓰는 요금제입니다. 개인이라면 건너뛰어도 됩니다.

| | Team 표준 | Team 프리미엄 |
|---|---|---|
| 가격(1명, 월) | 25달러 (연간 결제 시 20달러) | 125달러 (연간 결제 시 100달러) |
| 사용량 | Pro보다 많음 | 표준의 5배 |

Team은 2명부터 150명까지 쓸 수 있습니다. 개인 요금제와 달리 프로젝트를 팀원끼리 공유할
수 있고 결제를 한곳에서 관리할 수 있습니다. 회사 계정으로 로그인하는 기능(SSO)도 들어
있습니다.

보안이나 관리 기능이 더 필요한 조직은 Enterprise가 따로 있습니다. 좌석 요금(1명당 월 20달러,
연간 결제, 최소 20명)에 실제로 쓴 만큼 API 요금이 더해지는 방식입니다. 직접 가입하는 방식과 영업
담당과 상담해 정하는 방식이 있습니다.

## 결제 전에 알아 둘 것

- **표시된 가격은 세금 별도입니다.** 결제 화면의 최종 금액을 보고 결정하세요
- **결제한 금액은 원칙적으로 환불되지 않습니다.** 그래서 처음에는 월간 결제를 권합니다
- **해지해도 남은 기간은 그대로 씁니다.** 이미 결제한 기간이
  끝날 때까지 유료 기능이 유지됩니다
- **다음 결제를 막으려면 결제일 하루 전까지 해지하세요.** 공식 도움말은 다음 결제일보다 최소
  24시간 먼저 해지하라고 안내합니다
- **요금제는 바뀔 수 있습니다.** 가격과 구성이 수시로 조정되니 이 글의 숫자는 참고만 하고 결제
  직전에 공식 페이지를 확인하세요

## 한도에 걸린다고 바로 올리지 마세요

무료나 Pro에서 한도에 자주 걸린다고 해서 곧바로 요금제를 올릴 필요는 없습니다. 한도가 빨리
닳는 가장 큰 이유는 대화 하나를 길게 끌고 가는 것이라, 쓰는 습관만 바꿔도 같은 요금제로 훨씬
오래 쓸 수 있습니다.

주제가 바뀔 때 새 대화를 열고 질문은 모아서 한 번에 보내고 자주 쓰는 자료는 프로젝트에 올려
두는 것만으로도 차이가 납니다. 자세한 방법은
[클로드 사용량 제한 걸렸을 때](/claude/claude-usage-limit/)에 정리해 두었습니다.

그렇게 해 봤는데도 한 주에 몇 번씩 막힌다면 그때 올리면 됩니다.

클로드 코드에서는 `/compact` 명령어가 도움이 됩니다. 지금까지의 대화를 요약해서 줄여 주는
명령입니다. 저도 처음에는 이 명령어를 몰라서 쓰지 않았는데, 지금은 토큰 사용량을 줄이려고 자주
씁니다.

## 클로드 코드를 쓰려면

[클로드 코드](/claude/claude-code-what-is/)는 무료 요금제에서는 쓸 수 없고 **Pro부터** 됩니다.
클로드 앱과 같은 한도를 나눠 쓰기 때문에, 클로드 코드로 일을 많이 맡기면 앱에서 쓸 수 있는 양도
같이 줄어듭니다.

요금제에 가입하지 않고 API 키로 클로드 코드를 쓰는 방법도 있습니다. 이 경우는 정해진 월 요금이
아니라 쓴 만큼 돈이 나가는 방식이라 요금을 예측하기 어렵습니다. 처음 시작한다면 Pro 구독으로
쓰는 편이 마음이 편합니다.

클로드 코드를 매일 몇 시간씩 쓰게 되면 Pro 한도로는 금방 막힐 수 있습니다. 그때 Max를
고려하면 됩니다.
