기본 문법과 계산식 뽑는 법은 [CSS clamp() 기초](/blog/css-clamp-basics)에서 다뤘습니다. 이번 편은 "그래서 어디에 쓰느냐"입니다.

## clamp()가 잘 맞는 곳 / 안 쓰는 게 나은 곳

**잘 맞는 곳**은 화면 크기에 따라 눈에 띄게 달라져야 하는 값입니다.

- 제목(`h1`~`h3`)처럼 데스크톱과 모바일에서 크기 차이가 큰 요소
- 섹션 사이 세로 여백, 컨테이너 좌우 패딩
- 히어로 영역 높이, 큰 이미지의 최대 너비

**안 쓰는 게 나은 곳**도 있습니다.

- 본문 문단(`p`) — 15~18px 고정이 대체로 더 편합니다. 읽는 크기는 화면 폭보다 사용자 설정을 따르는 게 낫습니다.
- 테두리 두께, 아이콘 크기 같은 작은 고정 요소 — 유동적으로 만들 이득이 없습니다.

## 실전 1: 타이포 스케일 한 번에 잡기

제목 단계마다 `clamp()`을 쓰면 화면 크기와 무관하게 위계가 유지됩니다. 각 단계의 최소·최대만 서로 겹치지 않게 벌려 두면 됩니다.

```css
h1 { font-size: clamp(1.75rem, 1.3rem + 2vw, 2.5rem); }
h2 { font-size: clamp(1.4rem, 1.15rem + 1.1vw, 1.875rem); }
h3 { font-size: clamp(1.15rem, 1.05rem + 0.5vw, 1.375rem); }
```

`vw` 값을 제목이 클수록 크게 두면, 화면이 넓어질 때 큰 제목이 더 많이 자라 위계 대비가 살아납니다.

## 실전 2: 섹션 여백과 컨테이너 패딩

여백을 고정값으로 두면 모바일에서 너무 벌어지거나 데스크톱에서 답답해집니다. `clamp()`으로 한 번에 조절합니다.

```css
.section   { padding-block: clamp(2rem, 1rem + 5vw, 5rem); }
.container { padding-inline: clamp(1rem, 0.5rem + 2vw, 2rem); }
.stack > * + * { margin-top: clamp(0.75rem, 0.5rem + 1vw, 1.5rem); }
```

여백에 쓸 때는 최소값을 충분히 확보하는 게 중요합니다. 좁은 화면에서 `vw` 성분이 거의 0에 수렴하므로, 최소값이 곧 모바일에서의 실제 여백이 됩니다.

> **값 뽑기가 번거로우면** [CSS clamp() 생성기](/tools/clamp-generator)에 최소·최대 크기와 화면 너비 범위만 넣으세요. 위 예제처럼 `rem + vw` 형태로 바로 나옵니다.

## 실전 3: 유동 레이아웃

`gap`이나 `width`에도 그대로 쓸 수 있어서, 미디어쿼리 없이 카드 간격이나 사이드 여백을 조절할 수 있습니다.

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
  gap: clamp(0.75rem, 0.4rem + 1.5vw, 1.5rem);
}
```

`minmax()`가 열 개수를, `clamp()`이 간격을 맡아 레이아웃 전체가 중단점 없이 흐릅니다.

## 흔한 실수

- **최소·최대값 역전** — `clamp(2rem, …, 1rem)`처럼 최소가 최대보다 크면 브라우저는 최대값을 무시하고 항상 최소값을 씁니다. 값이 안 변하면 이 경우가 많습니다.
- **선호값을 순수 `vw`로만** — `font-size: 5vw`는 브라우저 확대에 반응하지 않아 WCAG 1.4.4(텍스트 크기 조정) 위반입니다. 선호값에 `rem`을 반드시 섞으세요.
- **변화가 너무 급함** — 좁은 화면 구간(예: 320→600)에 큰 변화를 몰면, 창을 조금만 줄여도 글자가 확 작아집니다. 두 목표점의 화면 너비 간격(예: 400→1200)을 넉넉히 잡으세요.
- **모든 곳에 적용** — 본문·버튼·라벨까지 전부 `clamp()`으로 만들면 유지보수만 어려워집니다. 크기 차이가 큰 곳에만 씁니다.
- **최소값·고정값을 rem이 아닌 px로** — `px`로 두면 사용자가 브라우저 기본 글꼴 크기를 키워도 따라오지 않습니다. 최소값과 선호값의 고정 부분 모두 `rem` 권장입니다.

## 요약

- `clamp()`은 제목·여백·레이아웃 간격처럼 화면에 따라 크게 달라져야 하는 값에 쓴다
- 본문 글자 크기는 고정이 대체로 낫다
- 여백에 쓸 때 최소값 = 모바일에서의 실제 값이므로 넉넉히 잡는다
- 선호값에 `rem`을 섞고, 최소 ≤ 최대를 지키고, 뷰포트 구간을 넓게 잡는다
