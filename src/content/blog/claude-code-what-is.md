## "클로드 코드"는 AI 이름이 아닙니다

클로드(Claude)는 Anthropic이라는 회사가 만든 AI입니다. ChatGPT나 Gemini와 같은
대화형 AI라서, claude.ai 웹사이트나 스마트폰 앱에서 질문을 입력하면 답을 해 줍니다.

그런데 "클로드 코드"라는 이름을 처음 들으면 조금 헷갈립니다. 코딩을 잘하는 새 AI가
나온 건가 싶기도 하고, 개발자용 앱을 따로 파는 건가 싶기도 하죠.

둘 다 아닙니다. 클로드 코드(Claude Code)는 새 AI가 아니라, 내 컴퓨터 안에서 클로드가
직접 일할 수 있게 해 주는 도구입니다. 머리는 그대로이고 손이 생겼다고 보면 됩니다.

채팅창에서 "이 코드 고쳐 줘"라고 하면 클로드는 고친 코드를 답으로 보여줍니다.
그걸 복사해서 내 파일에 붙여 넣고, 제대로 되는지 돌려 보는 건 내 일이었습니다.
클로드 코드에 같은 부탁을 하면 파일을 열어 고치고, 실행해서 되는지 확인하는 데까지
알아서 합니다.

이 글에서는 채팅과 무엇이 다른지, 어디서 쓰는지, 시작하려면 무엇이 필요한지를
차례로 봅니다. 설치하고 써 보는 과정은 [VS Code에서 클로드 코드 쓰기](/blog/claude-code-vscode/)에,
처음 해 둘 설정은 [초기 세팅 추천](/blog/claude-code-initial-setup/)에 따로 정리했습니다.

## 채팅 AI와 무엇이 다른가

같은 클로드인데 일하는 방식은 꽤 다릅니다.

| 구분 | 채팅 (claude.ai) | 클로드 코드 |
|---|---|---|
| 보는 범위 | 내가 붙여넣은 내용 | 작업 폴더 안의 파일 (필요한 걸 직접 찾아 읽음) |
| 고치기 | 고친 코드를 답으로 보여줌 | 파일을 직접 고침 |
| 확인 | 내가 실행해 보고 결과를 다시 알려줌 | 직접 실행해 보고 결과를 읽음 |
| 여러 파일 | 파일마다 따로 물어봄 | 한 번에 여러 파일을 고침 |

써 보면 확인 단계에서 차이가 제일 크게 느껴집니다. 채팅창의 클로드는 자기가 준 코드가
실제로 돌아가는지 알 수 없습니다. 에러가 나면 그 메시지를 복사해서 다시 물어봐야 했죠.
클로드 코드는 직접 실행해 보고, 에러가 나면 메시지를 읽고 다시 고칩니다. 둘 사이를
오가며 복사하던 일이 없어집니다.

모든 걸 묻지도 않고 해 버리는 건 아닙니다. 파일을 고치기 전에 매번 허락을 받게 할 수도
있고, 어디까지 맡길지는 사용하는 사람이 정합니다. 이 내용은 아래에서 따로 설명합니다.

## 어디서 쓸 수 있나

클로드 코드는 원래 터미널에서 쓰는 도구였습니다. 터미널은 마우스 대신 명령어를 글자로
쳐서 컴퓨터를 다루는 창인데, 익숙하지 않으면 막막하죠. 지금은 터미널을 몰라도 쓸 수
있는 곳이 여럿 생겼습니다.

| 쓰는 곳 | 특징 |
|---|---|
| 터미널 | 원래 형태. 기능이 가장 많음 |
| VS Code 확장 | 코드 편집기 옆에 대화 창이 붙음 |
| 데스크톱 앱 | Claude 앱의 Code 탭. 터미널 없이 사용 |
| 웹 (claude.ai/code) | 설치 없이 브라우저에서 사용 |

어디서 시작해도 괜찮습니다. 터미널에서 하던 대화를 VS Code에서 이어서 할 수도 있어서,
나중에 옮겨 가기도 어렵지 않습니다.

처음이라면 VS Code가 무난합니다. VS Code는 마이크로소프트가 무료로 배포하는 코드
편집기입니다. 파일 목록과 코드를 보면서 옆 창에서 대화할 수 있고, 클로드가 파일을 고치면
고치기 전과 후를 나란히 놓은 비교 화면을 띄워 줍니다. 무엇이 바뀌었는지 눈으로 보고
넘어갈 수 있다는 점이 처음 쓸 때 특히 도움이 됩니다.

## 무엇이 필요한가

무료로는 쓸 수 없습니다. 공식 문서 기준으로 Pro, Max, Team, Enterprise 요금제에 포함되어
있고 무료 요금제에는 들어 있지 않습니다. 요금은 자주 바뀌니 가입 전에 claude.com의
요금제 페이지를 확인하세요.

요금제마다 사용량 한도가 있습니다. 긴 작업을 여러 개 동시에 돌리면 금방 차고, 다 쓰면
한도가 다시 채워질 때까지 기다려야 합니다. 처음에는 한 번에 한 가지씩 맡겨 보면서
어느 정도 쓰면 한도에 닿는지 감을 잡는 게 좋습니다.

컴퓨터 사양은 크게 따지지 않습니다. Windows 10(1809 버전) 이상이나 macOS 13 이상,
메모리 4GB 이상이면 됩니다. 클로드 자체는 Anthropic의 서버에서 돌아가기 때문에
인터넷 연결은 꼭 있어야 합니다.

Windows를 쓴다면 [Git for Windows](https://git-scm.com/downloads/win)도 설치해 두세요.
없어도 클로드 코드는 동작하지만, 있으면 클로드가 쓸 수 있는 명령어가 늘어나서 작업 중에
막히는 일이 줄어듭니다.

## 허락은 어디까지 받나

처음 쓸 때 가장 걱정되는 건 "내 파일을 멋대로 고치거나 지우면 어쩌지"일 겁니다.
클로드 코드에는 이걸 정하는 권한 모드가 있습니다.

| 모드 | 묻지 않고 하는 일 |
|---|---|
| Manual | 파일 읽기만. 고칠 때마다 물어봄 |
| 편집 자동 승인 | 파일 읽기와 수정 |
| Plan | 파일 읽기만. 할 일을 계획으로 먼저 보여주고, 승인해야 고치기 시작 |
| Auto | 대부분. 위험해 보이는 동작은 다른 AI가 한 번 더 검사 |

공식 문서에 따르면 Pro, Max, Team 요금제는 Auto 모드로 시작합니다. 편하긴 한데, 처음
쓰는 입장에서는 클로드가 무엇을 했는지 모르는 채로 일이 끝나 버립니다. 익숙해지기
전까지는 Manual이나 Plan으로 바꿔 두고, 고치는 과정을 한동안 지켜보는 편이 낫습니다.

모드는 대화 도중에도 바꿀 수 있습니다. 터미널에서는 `Shift+Tab`을 누르고, VS Code에서는
입력창 아래에 있는 모드 이름을 클릭하면 됩니다.

비밀번호가 담긴 파일처럼 아예 건드리면 안 되는 것은 설정 파일에 금지 규칙으로 적어 둘 수
있습니다. 금지 규칙은 Auto를 포함해 어떤 모드에서도 지켜집니다. 적는 방법은
[초기 세팅 추천](/blog/claude-code-initial-setup/)에서 다룹니다.

## 시작해 볼 차례

처음이라면 VS Code에서 Manual이나 Plan 모드로 시작하는 게 가장 부담이 적습니다.

두 가지 방법으로 클로드 코드를 직접 설치하고 써 봅니다.
